# Admin Dashboard Guide
## Admin Analytics - Step-by-Step

## 1) Dashboard purpose
Admin dashboard provides live analytics and monitoring across all requests.

## 2) Access
1. Login with role `ADMIN`.
2. Navigate to `/admin`.
3. Review real-time cards and distribution panels.

## 3) Analytics cards
- Total Requests
- Pending (`PARALLEL_REVIEW`)
- Completed (`COMPLETED`)
- Halted (`HALTED`)

## 4) Distribution panels
- Requests per City
- Requests per Client

## 5) Operational usage
- Use admin panel for management reporting.
- Validate trend shifts across cities/clients.
- Cross-check unusual halted spikes with RH/Payment actions.
